A one-line roast of the gadget I use every day, written by a small Python program.

> My phone promised all-day battery, then died at 3 p.m. — the only thing it charges faster than its battery is my anxiety.

## Run

```sh
python3 main.py
```

This writes the roast to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).
